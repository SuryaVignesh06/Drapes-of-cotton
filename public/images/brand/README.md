# Brand Assets Directory

Place the official **Drapes of Cotton** logo files here:
- `/public/images/brand/logo.svg` (preferred vector lockup)
- `/public/images/brand/logo.png` (high-resolution fallback)

The `BrandLogo` component (`src/components/common/brand-logo.tsx`) is configured to render the official artwork from these paths once supplied, and falls back to an editorial wordmark placeholder without distorting or fabricating official artwork.
